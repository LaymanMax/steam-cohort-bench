# Canonical Data Dictionary

Every record in `steam-cohort-bench` originates from the Hugging Face dataset `FronkonGames/steam-games-dataset` and is normalized into canonical columnar types.

| Canonical Field           | Type        | Source Field              | Transformation / Derivation                                                    | Missing Value Semantics      | Analytical Use                             |
| ------------------------- | ----------- | ------------------------- | ------------------------------------------------------------------------------ | ---------------------------- | ------------------------------------------ |
| `app_id`                  | `VARCHAR`   | `appID`                   | Cast to string identifier                                                      | Never missing                | Primary key / Game identifier              |
| `name`                    | `VARCHAR`   | `name`                    | Trimmed string                                                                 | Defaults to empty string     | Search & display                           |
| `release_date`            | `VARCHAR`   | `release_date`            | Preserved original string                                                      | Empty if unrecorded          | Display in catalog                         |
| `release_year`            | `INTEGER`   | `release_date`            | Parsed 4-digit integer (`1980 - 2035`)                                         | `NULL` if unparseable        | Vintage filtering & release cadence charts |
| `price`                   | `DOUBLE`    | `price`                   | Numeric base store price                                                       | `0.0` for free / unpriced    | Pricing distributions & percentiles        |
| `is_free`                 | `BOOLEAN`   | `price`                   | `true` if `price == 0.0`                                                       | False                        | Free vs Paid segmentation                  |
| `estimated_owners`        | `VARCHAR`   | `estimated_owners`        | Raw SteamSpy range string                                                      | Preserved as-is              | Original bracket reference                 |
| `owners_lower`            | `BIGINT`    | `estimated_owners`        | Parsed lower bound integer                                                     | `0`                          | Sorting & bracket ordering                 |
| `owners_upper`            | `BIGINT`    | `estimated_owners`        | Parsed upper bound integer                                                     | `0`                          | Upper bound comparison                     |
| `owners_bracket`          | `VARCHAR`   | `estimated_owners`        | Normalized bracket label (`0 - 20K`, `20K - 50K`, etc.)                        | `'Unknown'` if unparsed      | Audience size distributions                |
| `windows`                 | `BOOLEAN`   | `windows`                 | Boolean flag                                                                   | `false` if null              | Platform support calculation               |
| `mac`                     | `BOOLEAN`   | `mac`                     | Boolean flag                                                                   | `false` if null              | Platform support calculation               |
| `linux`                   | `BOOLEAN`   | `linux`                   | Boolean flag                                                                   | `false` if null              | Platform support calculation               |
| `positive`                | `BIGINT`    | `positive`                | Steam positive player reviews                                                  | `0`                          | Review derivations                         |
| `negative`                | `BIGINT`    | `negative`                | Steam negative player reviews                                                  | `0`                          | Review derivations                         |
| `total_reviews`           | `BIGINT`    | Derived                   | `positive + negative`                                                          | `0` if no reviews            | Review volume percentiles & tiering        |
| `review_score_pct`        | `DOUBLE`    | Derived                   | `(positive * 100.0) / total_reviews`                                           | `NULL` if total reviews is 0 | Sentiment / rating percentiles             |
| `median_playtime_forever` | `BIGINT`    | `median_playtime_forever` | Steam median player playtime (minutes)                                         | `0`                          | Raw playtime metric                        |
| `median_playtime_hours`   | `DOUBLE`    | Derived                   | `median_playtime_forever / 60.0`                                               | `0.0`                        | User-facing playtime percentiles           |
| `genres`                  | `VARCHAR[]` | `genres`                  | Normalized array of genre strings                                              | `[]` if none                 | Cohort filtering & genre composition       |
| `categories`              | `VARCHAR[]` | `categories`              | Normalized array of feature strings                                            | `[]` if none                 | Cohort filtering & feature analysis        |
| `supported_languages`     | `VARCHAR[]` | `supported_languages`     | Interface & subtitle language array                                            | `[]` if none                 | Localization coverage calculations         |
| `full_audio_languages`    | `VARCHAR[]` | `full_audio_languages`    | Voiceover audio language array                                                 | `[]` if none                 | Voiceover vs subtitle comparison           |
| `is_playtest`             | `BOOLEAN`   | `name`                    | Flagged if title contains `playtest`, `closed beta`, `open beta`, `alpha test` | False                        | Quality mode exclusion                     |
| `is_sparse`               | `BOOLEAN`   | Derived                   | Flagged if genres, categories, and reviews are completely empty                | False                        | Quality mode exclusion                     |
| `quality_flags`           | `VARCHAR[]` | Derived                   | Audit tags (`missing_release_date`, `zero_owners`, etc.)                       | Empty slice                  | Data quality inspection                    |
